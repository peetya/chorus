# Contributing

Thanks for looking. Until December 7, 2026 I build Chorus on my own and don't merge outside pull requests,
while the first version takes shape. Issues and ideas are very welcome in the meantime, and I read all of
them.

After the results, pull requests are welcome as usual.

## Running it locally

See the README. In short: Node 24, `npm install`, `npm run dev`.

## Before you open a pull request

- One thing per pull request, with the template filled in
- `npm run typecheck && npm run lint && npm test` pass
- Conventional commit messages: `feat: ...`, `fix: ...`, `docs: ...`, `chore: ...`
